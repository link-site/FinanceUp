Credenciais de Acesso do Bot

Obtenha no Telegram com o @BotFather enviando o comando /newbot.

Seu ID no Telegram. Clique em Detectar Chat ID após enviar /start para o bot no Telegram.

Ações & Sincronização

Sincronização Automática em Segundo Plano Verifica novas mensagens do Telegram a cada 4 segundos

Como conectar passo a passo:

  1. Abra o Telegram, procure por @BotFather e mande o comando /newbot para criar seu bot.
  2. Copie o API Token gerado e cole no campo "Telegram Bot Token" acima.
  3. Abra o chat com o seu bot novo no Telegram e mande a mensagem /start ou menu.
  4. Clique no botão Detectar Chat ID acima para preencher seu Chat ID automaticamente.
  5. Clique em Salvar Credenciais e interaja com o menu Orçamento diretamente no Telegram!
