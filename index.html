Central de Integração: Google Forms & Bot

Automatize compras no cartão via Google Forms ou receba alertas no celular

Por que o Google Forms é a maneira mais simples no nosso ambiente?

Você cria um atalho do formulário na tela inicial do celular. Ao comprar algo na rua, responde em 3 segundos. O Google Apps Script envia o dado em tempo real para o banco da sua conta no app sem custos e sem servidores intermediários!

1 Crie seu Google Forms com estas 5 perguntas exatas:

Pergunta 1 (Lista Suspensa) Cartão -> Nomes dos cartões (ex: Nubank, Inter)
Pergunta 2 (Resposta Curta) Nome da Compra -> Ex: Tênis Nike, Almoço
Pergunta 3 (Número/Texto) Valor ou Valor (R$) -> Ex: 150.00 ou 150,00 (pode chamar apenas de "Valor")
Pergunta 4 (Lista Suspensa) Parcelas -> Ex: 1, 2, 3, 4, 5, 6, 10, 12
Pergunta 5 (Data) Data -> Data da realização da compra

2 Cole o Script Prontinho na Planilha de Respostas:

Na planilha do Google Forms, vá em Extensões > Apps Script, apague tudo e cole o código abaixo. Depois, clique no ícone de relógio (Acionadores) > Adicionar acionador > Selecione a função onFormSubmit no evento No envio do formulário e salve!

Alertas de Retorno no Bot / Celular

Quando você registra uma compra pelo Google Forms ou direto pelos botões no app, aqui estão as 3 maneiras mais simples de receber o retorno no seu dia a dia:

Opção A: Bot Gratuito do Telegram (Mensagem Instantânea)

No app do Telegram, busque por @BotFather e digite /newbot para criar o seu assistente. Ele te dará um Token de Acesso. No próprio Apps Script do seu Google Forms, adicione a chamada UrlFetchApp.fetch('https://api.telegram.org/botTOKEN/sendMessage?chat_id=SEU_ID&text=🛒 Compra registrada com sucesso!') para receber um aviso instantâneo no celular a cada nova compra!

Opção B: Resumo por E-mail (Google Workspace / Gmail)

No mesmo Google Apps Script da sua planilha, você pode ativar o envio gratuito por e-mail adicionando a linha MailApp.sendEmail(seuEmail, "🛒 Nova Compra no Cartão", "Sua compra foi cadastrada no FinanceUP!").

Opção C: Planilha Espelho no Google Drive

Todas as respostas enviadas ficam automaticamente salvas e organizadas na aba "Respostas > Planilha" do seu Google Forms, servindo como um backup em Excel em tempo real para auditorias lado a lado com o app!

Permissão do Google Forms no Firebase

Se o Google Forms retornou erro 403 Permission Denied, significa que o Firestore está bloqueando o script externo. Copie as regras abaixo e cole no seu Console do Firebase > Firestore Database > Regras:

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    // Permite que o Google Forms / Apps Script envie transações diretamente
    match /transactions/{txId} {
      allow read, write, create: if true;
    }
    
    function isAllowedUser() {
      return request.auth != null && (
        request.auth.uid == '2UP0Q0zULZVIS0M0qhXCRRRuzY63' ||
        request.auth.uid == 'oV78H7LwVjXo3tGq0LqS5Xw9s123' ||
        request.auth.token.email == 'marcioes411@gmail.com' ||
        request.auth.token.email == 'sousaleidiane242025@gmail.com'
      );
    }

    match /users/{userId} {
      allow read, write: if isAllowedUser();
    }
    match /transactions/{txId} {
      allow read, write, create, update, delete: if isAllowedUser() || resource.data.userId == request.auth.uid || request.resource.data.userId == request.auth.uid;
    }
    match /cards/{cardId} {
      allow read, write, create, update, delete: if isAllowedUser() || resource.data.userId == request.auth.uid || request.resource.data.userId == request.auth.uid;
    }
    match /categories/{catId} {
      allow read, write, create, update, delete: if isAllowedUser();
    }
  }
}

Por que o teste ou o Forms pode não ter gravado?

Siga este passo a passo rápido para descobrir exatamente o que aconteceu e resolver em segundos.

1 Verifique os Logs de Execução no Apps Script

No editor do Google Apps Script (onde você colou o código), clique no ícone de Execuções (um relógio/cronômetro no menu lateral esquerdo). Lá você verá todas as tentativas de envio, se houve erro (como 403, 400) ou se foi bem-sucedido.

2 Erro 403 (Permissão Negada)?

Se o log mostrar Status Code: 403, significa que as regras do Firestore estão bloqueando requisições externas sem login. Vá na aba 🛡️ 4. Regras do Firebase acima, copie as regras atualizadas e cole no seu Console do Firebase (Firestore Database > Rules) e clique em Publicar.

! Apareceu "Teste de Conexão" ao invés da compra real?

Isso acontece se você clicar no botão Executar diretamente dentro do editor do Apps Script. O script não tem como ler as informações do formulário dessa forma, então ele envia dados de teste apenas para provar que a conexão funciona.

Para testar com dados reais: Não clique em Executar! Preencha e envie o seu Google Forms de verdade (modo de visualização normal) e certifique-se de que o Acionador está ativado.

4 Acionador (Trigger) Configurado?

Se o Forms foi preenchido mas não disparou, verifique se você criou o acionador: No Apps Script, clique no ícone de Acionadores (relógio) > Adicionar acionador > Função: onFormSubmit > Evento: No envio do formulário.
